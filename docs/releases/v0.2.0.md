The first Research Bot release that updates itself.

## What's new

- **Automatic updates.** Windows and the Linux AppImage check GitHub Releases, download new versions in the background, and ask before restarting. You can turn this off in Account & preferences.
- **App icon.** A new icon for every platform, replacing the default Electron one.
- **Fixes from the code audit:**
  - Sign in with a different ChatGPT account after signing out.
  - Long notes no longer break the assistants.
  - Grammar reviews tolerate miscounted offsets.
  - Error messages read as plain sentences.
  - Note history is capped, and undo now has redo.
  - Tasks interrupted by a crash are marked as failed.
  - A bad CA certificate setting no longer stops the app from starting.
- **Smaller download.** The app archive went from 39 MB to 2.2 MB.

## Install

- **Windows:** `research-bot-0.2.0-win-x64-setup.exe`. It is unsigned, so SmartScreen may warn: choose "More info", then "Run anyway".
- **Linux:** `research-bot-0.2.0-linux-x86_64.AppImage`. Make it executable, then run it.

If you have 0.1.0, install 0.2.0 by hand this once, because 0.1.0 has no updater. Later versions arrive automatically.

Checksums are in `SHA256SUMS-linux.txt` and `SHA256SUMS-windows.txt`. macOS builds will follow once the app is signed.
