Research Bot on Android.

## What's new

- **Android app.** The full app runs on Android 8.0 and later (built for Android 16): projects, notes with undo and redo, the four agents, ChatGPT sign-in, Crossref source search, research plans, grammar review and export. It shares its backend code with the desktop app, so both behave the same way.
- **Android updates.** The Android app checks GitHub Releases, verifies the new APK's checksum and signing key, and asks before installing.
- **Phone layout.** Dialogs, the project drawer and fixed bars respect the status bar, the gesture bar and display cutouts. Notes also save when the app is sent to the background.

## Install

- **Android:** `research-bot-0.3.0-android.apk`. Open it on your phone and allow installs from your browser when asked. See [docs/android.md](https://github.com/Srimi1/research------bot/blob/main/docs/android.md).
- **Windows:** `research-bot-0.3.0-win-x64-setup.exe`, or let 0.2.0 update itself.
- **Linux:** `research-bot-0.3.0-linux-x86_64.AppImage`, or let 0.2.0 update itself.

Checksums are in `SHA256SUMS-android.txt`, `SHA256SUMS-linux.txt` and `SHA256SUMS-windows.txt`.
