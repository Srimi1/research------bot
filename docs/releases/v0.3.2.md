# Research Bot 0.3.2

A clearer, more useful research workspace on Android.

- An illustrated welcome screen with stronger text contrast and four assistant cards that open a new project in the chosen workflow.
- A project overview with real word, source and plan counts, plus a suggested next action based on the project's progress.
- An optional note outline and editable prompt shortcuts for methods, evidence and brainstorming. Prompts are prepared for review; they do not run automatically.
- Distinct assistant colors, larger controls, clearer empty states and more readable source metadata.
- A sliding navigation indicator, short screen entrances and gentle illustration movement, all respecting reduced motion.
- Notifications stay underneath dialogs so they cannot block form buttons.

Validated with the existing backend and browser workflow suites, additional phone workflow checks, Android release compilation, lint, APK signature verification and alignment checks.

The personal APK uses the same signing certificate as the previously supplied 0.3.1 APK and a higher Android version code, allowing installation as an update.
