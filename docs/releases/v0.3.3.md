# Research Bot 0.3.3

Reliability fixes and a complete repository audit, following the Android interface improvements in 0.3.2.

[**Download the signed Android APK**](https://github.com/Srimi1/research------bot/releases/download/v0.3.3/research-bot-0.3.3-android.apk). Android 8 or later is supported, with Android 16 targeted. Windows and Linux installers are available under **Assets**, along with checksums and update manifests.

- Android requests now reject responses and chunks that arrive after cancellation.
- Long research notes save up to the database's supported one-million-character limit.
- Public source-link checks consistently reject local address forms on every platform.
- Desktop text contrast is stronger, verified alongside phone layouts with accessibility checks.
- The dependency tree has no known npm audit advisories after compatibility-tested build-tool overrides.
- New audit skill, audit report, branding and contribution/security documentation, and phone UI previews.
- CI exposes a debug APK artifact; manual releases remain draft until all installer/APK uploads succeed.

The Android APK retains the personal signing certificate used by the previously supplied 0.3.1 and 0.3.2 APKs, allowing installation over those builds. Its checksum, certificate, package/version, alignment and unchanged source inputs are verified before publication; `BUILD_INFO-android.json` records the build details. If an existing app uses a different certificate, export projects before uninstalling it.

Windows and Linux installers are unsigned. A macOS installer is not included in this release.

See the [audit report](https://github.com/Srimi1/research------bot/blob/main/docs/audits/2026-10-06.md) for validation and remaining limits. Live ChatGPT sign-in and physical-phone behavior are still unverified.
