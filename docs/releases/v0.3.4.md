# Research Bot 0.3.4

Android startup and workspace initialization fixes.

[**Download the signed Android APK**](https://github.com/Srimi1/research------bot/releases/download/v0.3.4/research-bot-0.3.4-android.apk). Install over 0.3.3 to retain projects; the package and personal signing certificate are unchanged. Android 8 or later is supported, with Android 16 targeted.

- Fixed the shipped security policy blocking SQLite's WebAssembly. The workspace can now initialize its database; JavaScript eval remains blocked.
- Initialized AndroidX's splash-screen handoff before Capacitor/AppCompat startup.
- Added a production Android backend test for real SQLite and project persistence under the shipped CSP.
- CI and release checks now install the actual APK on Android 16, create a project, save notes and verify them after a cold restart. Signed APK releases stay draft until this check succeeds.

Windows and Linux installers, update manifests and checksums are attached under **Assets**. Desktop installers are unsigned; a macOS installer is not included.

The original 0.3.3 APK reached its welcome screen on the stock Android 16 emulator, but its database initialization failed under the shipped security policy. The reported immediate close on the physical OnePlus 7T Pro running Legion OS has not been reproduced there; device-specific validation and live ChatGPT sign-in remain open. See the [startup investigation](https://github.com/Srimi1/research------bot/blob/main/docs/audits/2026-10-07-android-startup.md).
