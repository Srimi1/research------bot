# Research Bot 0.3.5

Mac installers and an Android sign-in callback fix.

- [**Apple Silicon Mac DMG**](https://github.com/Srimi1/research------bot/releases/download/v0.3.5/research-bot-0.3.5-mac-arm64.dmg)
- [**Intel Mac DMG**](https://github.com/Srimi1/research------bot/releases/download/v0.3.5/research-bot-0.3.5-mac-x64.dmg)
- [**Signed Android APK**](https://github.com/Srimi1/research------bot/releases/download/v0.3.5/research-bot-0.3.5-android.apk)

The Mac edition includes local research projects, autosaved notes with saved-revision undo/redo, Crossref source discovery and reading notes, editable research plans, assistant review, task history and Markdown/JSON export through the Mac save dialog. Added native research menus, Command-key shortcuts, interface zoom and Dock reopening. See [the Mac installation and research guide](https://github.com/Srimi1/research------bot/blob/main/docs/macos.md).

Fixed a race where Android closed its OAuth callback server before a queued reply reached the browser, producing **“This sign-in is no longer active.”** The native bridge now acknowledges completed socket writes, and the shared authentication service waits before closing. Regression coverage checks both successful and rejected asynchronous callbacks; PKCE, state, nonce and identity verification remain in place.

Each Mac DMG must pass an installed-app runtime test on its matching architecture before publication. The actual signed APK must pass native launch, project/note saving and cold-restart checks on Android 16. Windows and Linux installers and their update manifests are also attached, with per-platform checksums.

**Mac installation:** drag Research Bot to Applications. The beta is ad hoc signed without Apple Developer ID signing/notarization; follow the guide's macOS Privacy & Security instructions if blocked. Mac updates are manual. Windows/Linux installers are unsigned. Android uses the existing personal certificate: install over 0.3.4 to retain projects.

Physical MacBook/OnePlus custom-ROM behavior, live ChatGPT account eligibility and inference remain unverified. The callback race was reproduced by an asynchronous transport regression test; a full live-account sign-in on the phone still needs confirmation.
