# Research Bot 0.3.8 — Android

This APK update fixes reproduced failures when a WebView lacks its optional timeout or UUID APIs. It also keeps app/WebView version information available when an optional Android query fails and labels saved errors as **Previous sign-in attempt**.

After a failed sign-in, open **Account & preferences → Check connection**. It tests native HTTPS, public identity endpoints and a deliberately invalid token request without using account credentials. **Copy connection results** provides a small report containing only versions, HTTP statuses and fixed error codes. A rejected dummy request verifies reachability, not a real account sign-in.

Install the APK over your existing app to keep projects and notes. It targets Android 16 and uses the existing signing certificate. Start a new **Continue with ChatGPT** attempt after installation.

This release publishes Android assets only. Source checks cover compatibility fallbacks and diagnostic redaction, production CSP, identity validation and persistence. Publication requires the actual signed APK to pass Android 16 launch and saved-project recovery; the upgrade check starts with the published 0.3.7 APK and verifies that its project and notes survive installing 0.3.8.

The maintainer still reports a fresh 0.3.7 failure on OnePlus/Legion OS. The underlying phone exception, live sign-in, account eligibility and inference remain unverified. If it fails again, report the fresh fixed error text and copied connection results; never share callback URLs, authorization codes or tokens.
