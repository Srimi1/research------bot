# Research Bot 0.3.9 for Android

This update fixes ChatGPT sign-in failing with `RB-AUTH-EXCHANGE-DNS` ("Android could not resolve the ChatGPT token server") even though **Check connection** succeeds.

**Cause.** After you approve access in the browser, the old app exchanged the authorization code while the browser was still in front. Android 15 and later block networking for an app in the background, and Data Saver and battery restrictions do the same. The blocked lookup surfaced as a DNS error on any Wi-Fi or mobile network. This was reproduced on the Android 16 emulator: the same request that succeeds with the app in front fails in 5 ms behind the browser.

**Fix.** The browser now shows "Authorization received. Return to Research Bot to finish connecting ChatGPT." Research Bot comes back to the front (switch to it yourself if Android does not), waits until Android allows its network, and only then completes the exchange. PKCE, state, nonce, identity verification, TLS and Keystore-encrypted credentials are unchanged.

Install the APK over your existing app to keep projects and notes. It uses the existing signing certificate and adds the normal network-state permission, which needs no prompt. Then start a new **Continue with ChatGPT** attempt.

Emulator checks cover the fixed exchange behind a real browser and the signed APK's fresh install, upgrade from 0.3.8 and cold restart with saved notes. Live sign-in on the reporting OnePlus 7T Pro (Android 16, Legion OS) is not yet confirmed. See the [investigation](https://github.com/Srimi1/research------bot/blob/main/docs/audits/2026-10-07-android-background-exchange.md).
