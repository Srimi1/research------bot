# Research Bot 0.4.0

Android ChatGPT sign-in stays alive while the browser is open, then exchanges the authorization code after Research Bot returns to the foreground. A short foreground service ("Connecting ChatGPT…") runs only during sign-in and stops on success, failure, cancellation or timeout. If Android still closes the app during consent, the next launch shows `RB-AUTH-INTERRUPTED` with an **Open battery settings** action. Set **Battery usage → Unrestricted** if interruptions repeat on Legion OS or another aggressive ROM.

**Install it over your existing app.** 0.4.0 is signed with the same certificate as 0.3.1–0.3.9 (SHA-256 `98580ca053712555a2b8a3a8fecfc15c85d83c5d192480e3b6b09ca13a633441`, also in `android/release-signing-certificate.sha256`), so projects, notes and settings are kept. Then start a fresh **Continue with ChatGPT** attempt.

Publication requires the exact signed APK to pass Android 16 fresh install, persistence and cold restart, plus an in-place upgrade from the published 0.3.9 APK with notes retained. Android 16 emulator checks without instrumentation cover 20- and 75-second consent, Data Saver and a sign-in interrupted by the app being closed. Live sign-in on the maintainer's OnePlus 7T Pro / Android 16 / Legion OS is confirmed separately. Multiple accounts and providers follow after that phone check.
