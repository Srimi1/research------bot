# Research Bot 0.4.0

Android ChatGPT sign-in stays alive while the browser is open, then exchanges the authorization code after Research Bot returns to the foreground. A short foreground service ("Connecting ChatGPT…") runs only during sign-in and stops on success, failure, cancellation or timeout. If Android still closes the app during consent, the next launch shows `RB-AUTH-INTERRUPTED` with an **Open battery settings** action. Set **Battery usage → Unrestricted** if interruptions repeat on Legion OS or another aggressive ROM.

**0.4.0 uses a new signing key and requires a fresh installation.** It cannot update 0.3.9 in place. Export every project and verify the saved files before removing the old app; uninstalling deletes local projects, notes and settings. Exports are JSON/Markdown archives and automatic project import is not available. The new certificate SHA-256 is `e07d0f1bb2e400e248c1b2af756d314686d912718127aed1e65d4344ad555a35`, also pinned in `android/release-signing-certificate.sha256`. Then start a fresh **Continue with ChatGPT** attempt. Later releases will retain this key.

Publication requires the exact signed APK to pass Android 16 fresh install, persistence and cold restart. An in-place upgrade from 0.3.9 is incompatible with this certificate change. Android 16 emulator checks without instrumentation cover 20- and 75-second consent, Data Saver and a sign-in interrupted by the app being closed. Live sign-in and running an agent on the maintainer's OnePlus 7T Pro / Android 16 / Legion OS still need checking separately. Multiple accounts and providers follow after that phone check succeeds.
