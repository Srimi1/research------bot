# Research Bot 0.4.0

Android ChatGPT sign-in stays alive while the browser is open, then exchanges the authorization code after Research Bot returns to the foreground. The short foreground service stops on success, failure, cancellation or timeout. If Android kills the app during consent, the next launch shows `RB-AUTH-INTERRUPTED` with an **Open battery settings** action. Set **Battery usage → Unrestricted** if interruptions repeat on Legion OS or another aggressive ROM.

This release uses a new signing key because the 0.3.x key was lost. **Export every project and verify the saved files before uninstalling the old app and installing 0.4.0.** Uninstalling deletes local app data. Exports are JSON/Markdown archives; automatic project import is not available. Check the new public certificate SHA-256 in `android/release-signing-certificate.sha256` against `BUILD_INFO-android.json` and the APK signature. Later 0.4.x releases retain this new key.

Release preparation is pending the new public fingerprint and signed Android 16 fresh-install, persistence and cold-restart checks. Live sign-in and running one agent on the maintainer's OnePlus 7T Pro / Android 16 / Legion OS remain separate from emulator checks. Multiple accounts and providers follow after that phone check succeeds.
