# Research Bot 0.4.1

Research Bot now shares one design system across desktop, Android source, and the browser: local Inter for body text and controls, Fraunces with optical sizing for headings, and shared typography, color, spacing, radius, shadow, and motion tokens. Existing layouts and the forest-green/ivory palette are retained. Small text is at least 11px; fonts work offline.

Screen and list entrances, button presses, card hover feedback, dialogs, sheets, toasts and navigation use calm motion. Content loading uses shimmer skeletons. Reduced motion disables every animation and transition, plus hover and press movement. Project data and the storage schema are unchanged.

## Android status

A regular signed Android 0.4.1 update is **not attached**. Android users can download the [verified 0.4.0 APK](https://github.com/Srimi1/research------bot/releases/download/v0.4.0/research-bot-0.4.0-android.apk). The configured release-key restore previously failed because `ANDROID_KEYSTORE_BASE64` was invalid; the previous 0.4.0 release used a prebuilt APK. Release signing remains blocked because the existing 0.4.0 private key is unavailable in usable form. No replacement key was generated.

Android 0.4.1 has version code 401. Before its release, the exact signed APK must pass startup/persistence and an upgrade from 0.4.0. The Android startup check now scrolls to restored notes that larger typography places below the viewport, while preserving its original persistence assertions. [Android CI status](https://github.com/Srimi1/research------bot/actions/runs/37808254737) is separate from signed-release validation. Live ChatGPT account and physical-device validation remain separate maintainer checks.
