# Research Bot 0.4.1

Research Bot has a shared design system across desktop, Android and the browser: locally bundled Inter for body text and controls, and Fraunces for headings. Shared typography, color, spacing, radius and shadow tokens preserve the layouts and forest-green/ivory palette. Small text is at least 11px on desktop, and phone text sizing follows the shared scale.

Screen changes, lists, buttons, cards, dialogs, sheets and toasts now have calm motion. Loading content uses shimmer skeletons. Every animation, transition and press/hover movement is disabled when the system requests reduced motion. Fonts work offline; only the Latin subsets ship, with their SIL Open Font License notices.

Projects, notes, settings and the data schema are unchanged. Android 0.4.1 uses version code 401 and must be signed with the same certificate as 0.4.0 for an in-place update. Installations from 0.3.x still require the [fresh-install precautions](../android.md#install) introduced in 0.4.0. No replacement signing key is being introduced.

This release is being prepared as a draft for build review. Planned desktop artifacts are a Windows installer, Linux AppImage and Apple Silicon/Intel Mac DMGs. A new signed Android APK remains pending restoration of the existing 0.4.0 signing configuration and validation of the exact APK, including an upgrade from 0.4.0. Only attached assets establish availability; existing download links continue to point to the published 0.4.0 APK.

The design-refresh source checks and [before/after screenshots](../screenshots/design-refresh/README.md) cover 1280px desktop, 412px phone and 320px narrow-phone browser layouts. That review records passing lint, formatting, 106 unit tests, the TypeScript/Vite/Electron build and the full UI suite; four bundled Latin WOFF2 assets; actual Inter/Fraunces glyphs; no overflow; and no animations or transitions under reduced motion. These are source and browser checks, not validation of the new native release artifacts. New installer and signed-APK results will be recorded after their release checks complete. Live ChatGPT sign-in and inference on the maintainer's phone remain a separate validation item.
