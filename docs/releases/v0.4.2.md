# Research Bot 0.4.2

Prepared release; the normal signed Android APK awaits restoration of the existing 0.4.0 keystore in GitHub Actions secrets.

- **Literature review:** select saved papers, compare themes or methods, and inspect numbered citations with supporting excerpts. Drafts remain separate from notes until accepted. Accepted reviews retain references and limitations through undo/redo and export.
- **Evidence checks:** reject citations to unselected papers, quotes absent from supplied material, and omitted selected sources. Saved snapshots keep old drafts readable when a paper changes or is removed. Verify the scientific claims against the original papers yourself.
- **Android packaging:** fail before producing an unsigned release or using a key that differs from the pinned 0.4.0 certificate. Verify the existing release key independently, and test a separate install-check APK on Android 8 and 16.

The literature review uses saved abstracts and researcher annotations. It does not automatically fetch full papers or conduct a systematic review. See the [guide](../literature-review.md).

A normal 0.4.2 APK must retain the 0.4.0 signing certificate and pass the release workflow’s actual signed APK installation, saved-note recovery and upgrade checks before publication. Do not uninstall your regular app to test a separate install-check APK; it uses a different package and its own local data. The original reported phone installation failure is not established by the available generic error dialog.
