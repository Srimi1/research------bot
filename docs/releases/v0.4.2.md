# Research Bot 0.4.2 — withdrawn separate-app build

The Android APK in this release used package `com.researchbot.android.fresh`. It installed a second app with separate storage and cannot update the original `com.researchbot.android` installation. The release has been withdrawn to draft and removed from Latest. Its APK and historical validation files remain only as private draft audit references.

Keep the original app and its saved projects. The duplicate app on a phone cannot be removed remotely by this release correction, and uninstalling either app deletes that app's local data.

The corrected 0.4.3 source retains the original application ID and signing-certificate requirement, adds visible manual update controls, and requires an actual in-place upgrade with saved-note recovery before Android publication. No compatible replacement APK has been built or released. The original keystore backup is unavailable; the [latest key check](https://github.com/Srimi1/research------bot/actions/runs/38051207293) failed because the configured secret contains no recoverable base64 keystore.

Published desktop installers remain in [0.4.1](https://github.com/Srimi1/research------bot/releases/tag/v0.4.1). The original Android APK remains in [0.4.0](https://github.com/Srimi1/research------bot/releases/tag/v0.4.0).
