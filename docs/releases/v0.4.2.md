# Research Bot 0.4.2

**Signed production APK:** `research-bot-0.4.2-android.apk` is the primary Android download attached to this draft. It appears as **Research Bot 0.4.2** and installs alongside the existing app using package `com.researchbot.android.fresh`.

Existing projects stay in the existing app. The fresh production app has separate local storage and does not automatically import old projects or update the legacy package in place. Keep the existing app installed. See the [fresh-install guide](https://github.com/Srimi1/research------bot/blob/46aa02e5aee895bdc7e331fd4a8cc5e634f7ebbb/docs/android-fresh-install.md).

## Changes

- **Literature review:** select saved papers, compare themes or methods, and inspect numbered citations with supporting excerpts. Drafts remain separate from notes until accepted. Accepted reviews retain references and limitations through undo/redo and export.
- **Evidence checks:** reject citations to unselected papers, quotes absent from supplied material, and omitted selected sources. Saved snapshots keep old drafts readable when a paper changes or is removed. Verify scientific claims against the original papers.
- **Production Android packaging:** use an independent production key and app identity while preserving the legacy app and certificate. Reject unsigned APKs, incorrect key/password/alias configuration, certificate mismatches and stale prebuilt artifacts. Disable native and WebView debugging and mixed content.

The literature review uses saved abstracts and researcher annotations. It does not automatically fetch full papers or conduct a systematic review. See the [literature review guide](https://github.com/Srimi1/research------bot/blob/46aa02e5aee895bdc7e331fd4a8cc5e634f7ebbb/docs/literature-review.md).
